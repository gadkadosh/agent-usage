# Usage

A minimal macOS menu-bar app for viewing usage. For now, it displays placeholder text.

## Requirements

- macOS 13 or newer
- Swift 6 / Apple Command Line Tools (or Xcode)

## Run

From this directory:

```sh
swift run
```

Look for the chart icon in the menu bar. Click it to see the placeholder and choose **Quit Usage** to stop the app.

`swift run` builds and launches an executable; it does not create an installable `.app` bundle. Packaging and a real usage data source are future steps.
